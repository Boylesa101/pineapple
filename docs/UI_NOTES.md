# Pineapple UI Notes

## Visual direction

- Sand-warm base with bright but controlled travel accents
- Rounded white cards with soft depth
- Premium minimal pineapple mark, not cartoon styling
- Poppins for headings, Inter for body

## Key surfaces

- Splash and lock screens use the pineapple mark as the main focus
- Home uses quick-glance cards and next-trip context
- Travel Mode switches to high contrast and large touch targets
- Family and traveller surfaces reuse the same rounded premium card language
- Export and backup flows should feel calm and explicit rather than technical
- Empty states stay polished and intentional rather than sparse

## Interaction notes

- Tabs should remain simple and predictable
- CRUD actions are intentionally direct for offline reliability
- Sensitive values default to hidden in vault and travel mode
- Traveller badges and chips add family scannability without becoming playful or cartoonish
