# Google Play Draft

## Short description

Local-first travel organiser for passports, tickets, packing, and trip details.

## Full description

Pineapple keeps your travel documents, bookings, packing lists, and key trip details together in one calm, offline-first organiser.

Built for Android-first travel use, Pineapple stores your structured trip data locally on the device, protects app access with a PIN, and keeps sensitive document previews hidden until you unlock them. No account is required for the core app, and Pineapple remains useful with no cloud dependency.

Use Pineapple to:

- Organise trips, travellers, flights, hotels, itinerary items, and emergency references
- Store passports, visas, GHIC / EHIC cards, travel insurance, boarding passes, and other local files in a secure vault
- Track document expiry dates with local reminder scheduling and clearer six-month passport warnings
- Open Travel Mode for quick, high-contrast access to the details you need at airports, hotels, taxis, and during emergencies
- Export encrypted local backups and printable trip summaries when needed

Pineapple is designed to feel calm, clear, and travel-ready while keeping your most important holiday information close at hand.

## Key feature bullets

- Offline-first trip organiser with secure local vault
- PIN lock, optional biometrics, and privacy-aware masking
- Document expiry warnings and local reminder scheduling
- Packing lists, itinerary timeline, and emergency references
- High-contrast Travel Mode for quick access under pressure
- Encrypted local backup and restore

## Permissions notes

- Notifications: only for local trip and document reminders
- Photos/media: only when the user chooses a local image to import
- File access: only when the user explicitly chooses a local file to import or restore
